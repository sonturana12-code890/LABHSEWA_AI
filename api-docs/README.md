# 🇮🇳 LABHSWEA AI – AI-Powered Government Welfare Assistant






> **"Every Citizen Deserves to Know What They're Entitled To."**



**LABHSETU AI** is an AI-powered digital platform that simplifies access to Government Welfare Schemes for every Indian citizen. Using Artificial Intelligence, multilingual support, and personalized eligibility analysis, the platform helps users discover, understand, and apply for schemes with ease.



---



# 🌟 Problem Statement



Millions of eligible citizens fail to receive government benefits because:



- Lack of awareness

- Complex eligibility criteria

- Multiple government portals

- Language barriers

- Difficult application procedures

- Limited digital literacy



Samarthya AI bridges this gap by providing a single intelligent platform for discovering and accessing government welfare schemes.



---



# 💡 Solution



Samarthya AI acts as an AI-powered welfare assistant that:



- Understands citizen profiles

- Identifies eligible government schemes

- Explains eligibility in simple language

- Guides users through the application process

- Supports multiple Indian languages

- Tracks application progress

# 🔄 Workflow



1. User creates an account.

2. User enters personal details.

3. AI analyzes profile.

4. Government scheme data is fetched.

5. Eligible schemes are identified.

6. AI explains benefits and eligibility.

7. User applies through the official portal.

8. Application progress is tracked.

# 🚀 Installation



Clone the repository



```bash

git clone https://github.com/yourusername/Samarthya-AI.git

```



Navigate into the project



```bash

cd Samarthya-AI

```



Install dependencies



```bash

npm install

```



Run the development server



```bash

npm run dev

```



Backend



```bash

cd backend

npm install

npm start

```
